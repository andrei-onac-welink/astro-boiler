## Repository-owned content

Static Pages live with the code and use ordinary Markdown. They are appropriate for content that changes with a deployment rather than through the CMS.

## Editing

Add another Markdown or MDX file to `src/content/static-page`. Its filename becomes the default root-level URL, and an optional `slug` frontmatter value can override it.
